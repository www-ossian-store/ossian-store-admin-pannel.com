Fix Token Orders HTTP 403

HTTP 403 ka matlab hai ke Firebase Firestore Security Rules token_orders collection ko read karne se rok rahe hain. Isay theek karne ke 2 tareeqe hain:

Option 1: Firebase Console Rules Update Karein

Firebase Console → Firestore Database → Rules mein yeh add karke Publish karein:

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /token_orders/{docId} { allow read, write: if true; } match /{document=**} { allow read, write: if true; } } }
Option 2: Firebase Auth Sign-In (Agar Rules mein request.auth != null laga hai)
